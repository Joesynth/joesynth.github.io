<h3>Alto nível e baixo nível</h3>

São os dois tipos de linguagens de programação.

<h6><img class="" src="https://www.ssla.co.uk/wp-content/uploads/2020/10/Low-Level-Developer-1.png" width="479" height="316" />
Baixo Nível</h6>
<span style="color: #0000ff"> <em>low level</em></span>.

São geralmente mais próximas do código de máquina e, portanto, oferecem maior controle sobre o <em>hardware</em>. São frequentemente usadas para programar sistemas operacionais, drivers de dispositivos e outras aplicações de nível de sistema.
👍️ Ofereçam maior controle e desempenho.
👎️ Geralmente exigem mais tempo e esforço para escrever código e depurá-lo.

<h6>Alto nível</h6>
<span style="color: #0000ff"><em>high level</em></span>.

Ex.: JavaScript, Python, Java, Ruby, PHP.

Tem recursos mais avançados para facilitar a escrita de código e aumentar a produtividade do programador. Geralmente exigem menos linhas de código.
👍️ São mais fáceis de usar e podem ser mais produtivas.
👎️ Podem sacrificar o controle e o desempenho em comparação com as linguagens de baixo nível.

<h3>C: alto ou baixo nível?</h3>

A linguagem C é uma das principais para conhecermos. Por vezes vemos gente se referindo à C como baixo nível, e outras pessoas dizendo que é alta. Em suma, ela combina características de linguagens de alto nível com linguagens de baixo nível. Ela pode ser considerada de nível intermediário.

<h6>O que é uma linguagem de script?</h6>
É qualquer linguagem que for usada para escrever um <em>script</em>. E script?
Digamos que, se formos escrever uma aplicação inteira e executarmos de forma independente, não será um <em>script</em>. Por outro lado, podemos entender que o JavaScript estende a habilidade do <em>browser</em> dando características adicionais à página, portanto é um <em>script</em>.

<h3>Linguagem Compilada ou Interpretada</h3>

<strong>Código fonte</strong> É escrito por você em tal linguagem. Ele tem o conjunto de palavras, símbolos escritos de forma ordenada, instruções...

A princípio, você desenvolvedor ou programador escreve esse código fonte por um Editor de Texto. Depois, para executá-lo, pode ter atitudes diferentes conforme o tipo de linguagem que usou para escrever o código fonte.

<h3>GCC</h3>

🤔️ Richard Stallman.
1987.
✏️ C, C++.
💽️ gnu.org
📜️ GPL.
🖥️ Linux, BSD

<em>Software</em> compilador para a maioria dos projetos GNU/Linux. Com milhões de linhas de código, é um dos maiores programas gratuitos. Ele desempenhou um papel importante no crescimento do software livre; seja como ferramenta, seja como exemplo.

Está disponível para muitos sistemas embarcados, por ex., chips baseados em ARM.

Lida com linguagem C, C++ e outras. Cada um dos compiladores de linguagem é um programa separado que lê o código-fonte e gera o código de máquina.

Em si, o GCC usa outras ferramentas adicionais, muitas instaladas por padrão em muitas distribuições Linux (mas que, normalmente, não estão presentes nas instalações do Windows)

<pre>C++ é uma linguagem muito usada também em robótica.</pre>
